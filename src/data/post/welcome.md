你好，欢迎来到高性能嵌入式实验室 · IO 社的主页。

这里有一群热爱技术和折腾的人。我们希望把想法变成真实的作品，也把项目实践、分享与交流中的收获记录下来。

## 你可以在这里找到什么？

- **社团介绍**：认识 IO 社，了解互联网、AI 芯片、物联网与嵌入式、元宇宙和人工智能五大方向。
- **文章与动态**：后续将在这里整理知识分享、学习笔记和组织动态。
- **活动记录**：为讨论中的发现和共同实践留下文字记录。

## 一起完善这个空间

网站也会随着内容慢慢生长。如果发现问题，或者有改进建议，欢迎在[网站仓库](https://github.com/io-club/io-club.github.io)提出 Issue 或 Pull Request。

也可以访问 [IO Club 的 GitHub 主页](https://github.com/io-club)，看看正在发生的探索。

从一个问题、一篇文章、一次分享开始。很高兴在这里遇见你。
