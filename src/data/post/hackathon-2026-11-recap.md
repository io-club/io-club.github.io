2026 年 11 月 7 日（周六）**09:30**，IO 黑客松正式开始。经过一个周末的开发与实践，活动于 **11 月 8 日（周日）17:00** 顺利结束。

感谢每一位带着想法来到现场的同学。这个周末，我们又一起把想法向前推进了一步。

## 活动成果

本次活动参与人数为 **11 人**，实际签到 **9 人**，最终孵化出 **2 件完赛作品**。

从一个想法开始，到写下代码、调试功能，再到交出作品，黑客松给了大家一个集中动手的周末。完赛也为后续的分享和继续开发留下了起点。我们希望这些作品在比赛结束后，仍有机会被完善、被使用。

## 模型调用支持

比赛期间，赛方提供了 **限时不限量的模型调用 Token**，覆盖 **DeepSeek、GLM、MiniMax 以及 GPT 系列模型**，供参赛者在活动期间使用。

感谢 [shirosora.cn](https://api.shirosora.cn/) 对本次 IO 黑客松的赞助，也感谢所有参与者用实际作品为这个周末留下记录。

## 最终奖品

本次活动的最终奖品如下：

| 名次       | 奖品                                 |
| ---------- | ------------------------------------ |
| 第一名     | 价值 **300 元**的 DeepSeek API Token |
| 并列第二名 | 价值 **200 元**的 DeepSeek API Token |

希望这份模型调用资源能陪伴获奖者继续完善作品，也支持下一次尝试。

## 下周茶话会分享

**下周的 IO 社茶话会将邀请本次黑客松第一名进行分享。** 欢迎大家一起来听听作品背后的想法与开发经历，也把自己的问题带到交流中。

比赛结束后，我们还可以继续聊代码、聊实现，让一次活动中的经验被更多人看见。

## 以后每月举办一次

**今后，IO 黑客松将每月举办一次。** 我们希望把集中动手做项目的机会变成社团的常态，让更多想法有机会落地，也让大家在一次次实践中找到搭档、积累经验。

欢迎继续关注 IO 社博客，或加入 QQ 群 **163194527**，了解后续黑客松与茶话会的安排。

下次黑客松，带上你的新想法，我们继续一起做。
